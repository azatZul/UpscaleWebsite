Получение успешно, сканирование и индексирование разрешены, Google выбрал проверенный URL каноническим. В деталях старого обхода sitemap отмечена временная ошибка обработки, но свежая отправка sitemap уже имеет статус «Успешно».

Sitemap при этом обработан успешно.
- Сводные отчёты нового ресурса Google пока обрабатываются; интерфейс рекомендует повторить проверку примерно через день.
- Яндекс Вебмастер: добавлен `https://upscales.app`, владение подтверждено DNS. [Открыть ресурс](https://webmaster.yandex.ru/site/https:upscales.app:443/dashboard/). Использован аккаунт, уже открытый в Chrome.

## Подтверждённые возможности улучшения

1. **Изображения: наибольший резерв объёма загрузки.** Оценка PageSpeed: 1711 KiB для главной, 1570 KiB для русской главной, 372 KiB для инструмента. Например, `girls_after.jpg` — 742,4 KiB, исходник 3010×2006 при отображении 366×244; `hero_spiderman_after.jpg` — 217 KiB, исходник 2000 пикселей по ширине при отображении 411 пикселей; `slowmo_thumb.jpg` — 142,3 KiB при отображении 84×62. Стоит генерировать варианты размеров и использовать `srcset`/`sizes`; для сравнений сохранить достаточную детализацию с учётом DPR и ползунка «до/после». Экономия байтов не равна обещанному ускорению LCP.
2. **CSS блокирует первый рендер.** На главной `assets/site.css?v=ad293f46` — 24,1 KiB передачи, оценка экономии 140 мс. Русская главная — 240 мс, инструмент — 300 мс. Оптимизация критического CSS имеет меньший объём эффекта, чем уменьшение загрузки изображений. LCP-элемент главной в отчёте — текстовый `h1`, задержка отрисовки 1330 мс; считать главным LCP-элементом картинку неправильно.
3. **Кэш изображений: вторичный приоритет.** PageSpeed показывает TTL 7 дней и оценку экономии повторных загрузок 247 KiB на главной. Продлевать срок стоит вместе с версионированием URL, чтобы обновления картинок доходили до пользователей.
4. **Доступность: контраст и порядок заголовков.** Автоматический аудит отмечает эти два класса замечаний на всех трёх страницах. Это требует отдельной проверки конкретных элементов, не является доказанным запретом индексации.

Оптимизации производительности по результатам этой проверки не вносились.
