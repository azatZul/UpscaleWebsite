- [Сводка](https://webmaster.yandex.ru/site/https:upscales.app:443/dashboard/): уведомление о временной остановке обновления данных.
- [Статистика запросов](https://webmaster.yandex.ru/site/https:upscales.app:443/efficiency/statistics/): выгрузка отключена, кнопки CSV/XLS неактивны. UI возвращает диапазон 06.09–06.10.2026 даже при попытке задать ноябрьские даты через адрес отчёта. Актуальные запросы, показы, клики и позиции не получены.
- [Страницы в поиске](https://webmaster.yandex.ru/site/https:upscales.app:443/indexing/searchable/): графики и выгрузка недоступны, предупреждение о задержках/остановке обновления. Полный список страниц и исключённых страниц отключён. Пустая таблица изменений не доказывает отсутствия страниц в индексе.
- [Sitemap](https://webmaster.yandex.ru/site/https:upscales.app:443/indexing/sitemap/): режим только для чтения, добавление и переобход sitemap отключены.

## Публичные страницы до публикации

`sitemap.xml` — исходный опубликованный файл с **120 URL**, из них 7 старых страниц инструмента. `http-baseline.json` содержит результаты 144 проверок, конечные адреса, title, meta robots, canonical и SHA-256 HTML. HTTP-проверка не устанавливает индексацию.

- Все 120 URL sitemap: HTTP 200, canonical совпадает с URL.
- 21 новый URL `free/`, `creative/`, `restore/` на семи языках: HTTP 404. Это ожидаемое состояние до выпуска.
- Старые EN/RU `?mode=device`: HTTP 200 с canonical на `/upscale/` соответствующего языка.
- В `html/` сохранён старый HTML семи языковых инструментов и двух вариантов с `?mode=device`.

Проверка выполнялась через curl. Первоначальная попытка Python urllib получила 403 от периметра; она заменена curl-снимком и не используется как доказательство недоступности сайта.

## Сравнение после выпуска

Отсчёт 2–4 недель вести от фактической публикации, записанной в журнале выпуска. Повторить те же фильтры и отдельно сравнить `/upscale/`, `/upscale/free/`, главные и гайд 4K в каждом языке. Учесть старые query-адреса и задержку отчётов. Бренд `uscale` и неоднозначный `upscale` анализировать отдельно.

Для обнаружения конкуренции выгрузить запросы отдельно по каждой из двух бесплатных страниц, проверить общие небрендовые запросы, динамику кликов/показов/позиций и выбранный Google canonical. Единичное пересечение на такой небольшой выборке не даёт достаточного вывода. Если страницы устойчиво конкурируют за один кластер, поставить canonical `/upscale/free/` на `/upscale/` **того же языка**, затем согласовать sitemap и внутренние ссылки. Пока canonical не менять.

Если Яндекс остаётся ограничен, повторно зафиксировать недоступность и сравнить только доступные источники. Не подменять неизвестные показатели нулями.
