## Рекомендации

1. Оставить `noindex` у отдельных альбомов и служебных результатов. Не запускать «Проверить исправление» для намеренного запрета.
2. Для нескольких приоритетных страниц из оставшихся 37 выполнить индивидуальную проверку URL и live test, затем при необходимости запросить индексацию. Приоритет — важные коммерческие страницы и статьи; служебным документам достаточно обычного обхода.
3. Проверить у непросканированных страниц наличие обычных HTML-ссылок с уже проиндексированных тематических страниц. Размещения в sitemap недостаточно для гарантии обхода и индексации.
4. Если после следующих обходов статьи остаются вне индекса, оценить их самостоятельную пользу, близость тем друг к другу и качество переводов. По одному статусу отчёта нельзя доказать проблему качества или конкретную причину решения Google.
5. Повторно сравнить число проиндексированных URL через 1–2 недели. Не менять даты lastmod без реального обновления содержания и не отправлять один URL многократно ради ускорения.

Google не гарантирует включение каждой технически доступной страницы в индекс.
